# Modo offline
Se prepara al iniciar sesión online como cliente o empleado. Se guarda una instantánea local de tarjetas (sin pases de canje) y reglas del empleado, con acceso local máximo de 24 horas. El shell público no cachea respuestas privadas de API. En caja se escanean identificadores, se selecciona el establecimiento y se guardan como máximo 50 compras pendientes por cuenta. La sincronización usa la sesión real y valida los permisos y reglas vigentes de PostgreSQL. Una operación tiene un UUID idempotente. La hora de captura se conserva en offline_award_receipts y la hora contable es la de validación. Los límites de frecuencia y cupo se aplican al sincronizar; una operación rechazada se muestra para revisión. No hay canjes offline. Las compras pendientes se conservan al cerrar sesión y solo se reenvían con la cuenta original. No se garantiza la persistencia si el usuario limpia los datos del navegador.
